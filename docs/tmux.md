# tmux configuration

The tmux prefix is `<C-Space>`, the default shell is Zsh, and windows and panes
use one-based indexing. Mouse support and vi-style copy mode are enabled.

The status bar expects the optional `wifi` and `battery --tmux` commands on
`PATH`. Missing commands affect only their status segments.

See [keymap.md](keymap.md) for the canonical list of custom key bindings.
